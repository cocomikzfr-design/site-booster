# Prompts d'images

Règles communes (voir `REGLES-IP.md`) : boîtiers vides ou avec des coffrets **fictifs** à motifs abstraits,
aucun logo, aucun texte, aucun personnage, aucun nom de jeu. Lumière douce venant du haut à gauche.

- **Photos produit** : fond `#F3EFE7` (papier ivoire), 2000 × 2500 px, le produit occupe ~75 % de la hauteur.
- **Images vitrine** (`custom.image_vitrine`) : PNG **transparent**, 1200 × 1500 px, produit détouré, vue de face,
  légère ombre de contact supprimée (le thème dessine l'ombre et le reflet).
- **Image de partage** : 1200 × 630 px (réglage Marque > Image de partage).

Chaque prompt se termine par : `No text, no logos, no characters, no brand names.`

```
Studio product render of an empty clear acrylic display case for a collectible card box, thick 5mm acrylic,
polished edges, magnetic lid with a thin brass-tinted seam, three-quarter view from slightly above, soft top-left light,
subtle edge highlights, transparent background, photorealistic, 1200x1500. No text, no logos, no characters, no brand names.
```
